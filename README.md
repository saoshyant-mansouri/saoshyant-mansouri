## ◆ The Shape of an Agent I Trust

A grounded pipeline has to be allowed to say *no*. Both branches below end in a refusal
path, and nothing reaches the client that isn't traceable to a retrieved source.

```mermaid
%%{init: {'theme':'base','themeVariables':{'fontFamily':'ui-sans-serif, system-ui','fontSize':'15px','lineColor':'#8B5CF6','titleColor':'#A78BFA','textColor':'#8B949E','edgeLabelBackground':'#8B5CF6'},'flowchart':{'nodeSpacing':30,'rankSpacing':32,'wrappingWidth':340,'curve':'basis'}}}%%
flowchart TD
    Q(["User question"]) --> R{"Route"}

    R -->|"documents"| H["Hybrid retrieve · SIMD cosine + BM25 · fused by RRF"]
    R -->|"metrics"| S["Retrieve schema · 226 tables · 1-hop FK graph · write T-SQL"]

    S --> V{"ScriptDom:<br/>one SELECT?"}
    V -->|"no"| X["Refuse · and say why"]
    V -->|"yes"| E["Execute · db_datareader · 5s cap"]

    H --> A["Compose answer · every sentence bound to a retrieved chunk"]
    E --> A
    A --> C{"Cited?"}
    C -->|"no"| X
    C -->|"yes"| O(["Stream to the client · show the SQL it wrote"])

    classDef io   fill:#4F46E5,stroke:#312E81,color:#FFFFFF
    classDef gate fill:#B45309,stroke:#78350F,color:#FFFFFF
    classDef work fill:#0E7490,stroke:#164E63,color:#FFFFFF
    classDef bad  fill:#BE123C,stroke:#881337,color:#FFFFFF
    class Q,O io
    class R,V,C gate
    class H,S,E,A work
    class X bad
```
